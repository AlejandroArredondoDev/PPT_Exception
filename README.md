# 🟢 PPT_Exception

> *"Has encontrado una grieta en la Matrix."*

**PPT_Exception** es un juego web interactivo de **Piedra, Papel, Tijera** ambientado en el universo de *Matrix*. Enfréntate al agente de seguridad de la IA (AI Smith), burla los sistemas de defensa y logra descifrar el firewall antes de que te denieguen el acceso.

## 🚀 Características Principales

* **Estética Matrix Inmersiva:** Interfaz inspirada en terminales ciberespaciales, con fuentes personalizadas de Google Fonts y efectos visuales de código.
* **Precisión Quirúrgica:** Elementos interactivos circulares optimizados mediante CSS (`border-radius`, `drop-shadow` y control estricto de eventos de ratón) para evitar clics fantasma.
* **Sistema de Puntuación First-to-3:** Partidas dinámicas al mejor de 3 puntos contra la IA.
* **Pantallas de Fin de Partida Cinemáticas:** Transiciones limpias sin parpadeos gracias a la precarga de imágenes en memoria (`Image()`), mostrando pantallas finales de victoria o derrota. 
* **Diseño Responsivo:** Adaptado mediante media queries para escritorios, tablets y dispositivos móviles.

---

## 💻 Tecnologías Utilizadas

* **HTML5** (Estructura semántica)
* **CSS3** (Flexbox, efectos, transiciones y diseño responsivo)
* **JavaScript (Vanilla)** (Lógica de juego, gestión de estados, manipulación del DOM y precarga de recursos)
